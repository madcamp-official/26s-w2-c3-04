# 로고 파일 넣는 법

이 폴더에 학교별 로고 이미지를 넣으면 앱이 자동으로 인식해서 씁니다.

파일명 규칙: `학교키.png` (또는 .jpg, .jpeg, .svg, .webp)

예시:
- logos/korea.png   (고려대)
- logos/kaist.png   (카이스트)
- logos/ewha.png    (이화여대)
- logos/hanyang.png (한양대)

전체 학교키 목록은 index.html 안 "대학교 프레임" 패널 설명 문구를 참고하세요.

로고가 없는 학교는 자동으로 학교색 원 안에 이니셜을 넣은 대체 배지로 표시됩니다.
